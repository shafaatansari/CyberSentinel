# CyberSentinel 🛡️

CyberSentinel is a personal security monitoring platform built with Python, Flask, and SQLite.

## Features

- 🔐 User authentication
- 🚨 Security alerts
- 📋 Security event monitoring
- 🔑 Password strength analysis
- 🌐 Suspicious URL analysis
- 🛡️ File integrity monitoring using SHA-256
- 📊 Security score
- ⚙️ User settings

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
